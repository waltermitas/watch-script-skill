# Script Validation Checklist

Purpose: an objective, binary (PASS/FAIL) acceptance checklist for validating a generated "Brothers in Watches" single-watch showcase YouTube script. Every item below is checkable by inspecting a finished script — no subjective judgement. If an item can't be answered yes/no from the script alone, it FAILS.

## Structure

- [ ] All required long-video segments present, in order: (1) Cold open, (2) The promise, (3) History — one angle, (4) Signature-feature deep dive, (5) The piece in hand, (6) Dating & authentication, (7) The flaw, movement & condition, (8) Market & value, (9) On the wrist / who it's for, (10) Verdict/close, (11) CTA.
- [ ] Cold open is ≤60 spoken words.
- [ ] Total long-video narration is 2,200–2,600 spoken words.
- [ ] Chapter timestamps are present.

## Retention

- [ ] A single stated "master loop" (the one question the whole video answers) is written explicitly in a retention map.
- [ ] 2–3 open loops are present, each labelled with where it opens and where it closes.
- [ ] Each open loop is closed before the next one opens.
- [ ] A labelled micro-hook transition line is present at every segment boundary (1→2 through 10→11).
- [ ] A mini-payoff is identifiable in each of the middle segments (history through market & value).
- [ ] At least one contrarian/curiosity-gap beat is present.
- [ ] No "welcome back" / "hey guys" / sponsor / "so I've been thinking" preamble anywhere in the cold open.

## Short cut (~1.5 min)

- [ ] A separate ~1.5-minute (90s) short cut is present.
- [ ] The short's spoken narration is ≤ ~260 words.
- [ ] The short's first spoken line and first on-screen text are the hook (the core contradiction/claim), with no preamble.
- [ ] The short delivers ONE core idea (not the full long-video outline).
- [ ] The short ends with a follow/subscribe CTA.
- [ ] On-screen text beats (timecoded) are present.
- [ ] A caption with hashtags is present.

## Voice

- [ ] Cold open is prose, not a bulleted or comma-separated fact list.
- [ ] Correct horological terminology is used (no dumbed-down substitutes).
- [ ] Tone is luxury experiential + educational (not casual vlog filler).

## Facts

- [ ] Every factual claim (dates, specs, production numbers, prices) carries a confidence tag or is marked `⚠️ verify`.
- [ ] Market/value comps cite Everywatch realized prices where available.
- [ ] Chrono24 is used only for asking prices and is labelled as such.
- [ ] No fabricated numbers, provenance, or specs; where a comp can't be found, a clearly-labelled range is given instead of an invented figure.

## SEO / Package

- [ ] 3–5 title options are present.
- [ ] Every title is brand front-loaded.
- [ ] Every title is ≤100 characters (count the characters).
- [ ] A video description is present.
- [ ] A pinned-comment hook is present.

## Blog

- [ ] A companion blog article is present.
- [ ] The blog article has its own SEO title and meta description.
- [ ] The blog article does not contradict any fact stated in the script (reuses the same research).

## Output

- [ ] The whole thing is a single Markdown file at `scripts/YYYY-MM-DD-<watch-slug>.md`.
- [ ] The single file contains BOTH the long-video script (narration + a b-roll/pattern-interrupt column) AND the ~1.5-min short cut, plus the title pack and the blog article.
